  - `coarsen(self, factor: int = 2, min_size: int = 4) -> Domain`
  - `coords(self, shape=None, device=None, dtype=None) -> torch.Tensor` — Normalized cell-centered grid, shape ``(*shape, ndim)`` with values in ``[-1, 1]``.
  - `from_dict(d: dict) -> Domain`
  - `from_spacing(shape: Sequence[int] | int, spacing: float | Sequence[float], origin: float | Sequence[float] = 0.0, axes: Sequence[str] | None = None) -> Domain` — Domain from grid shape and physical cell size (e.g. NeTMY: 64 px × 20 nm).

  - `numel` (property)
  - `physical_coords(self, shape=None, device=None, dtype=None) -> torch.Tensor` — Physical cell-centered grid, shape ``(*shape, ndim)``.

  - `to_dict(self) -> dict`
  - `to_normalized(self, x: torch.Tensor) -> torch.Tensor` — Map physical coordinates ``(..., ndim)`` to ``[-1, 1]``.

## `nefi.priors`

The prior catalogue: what you physically know about the unknown → heads, losses, hints.

### `class Binary(lo: float = 0.0, hi: float = 1.0, sharpen: bool = True, eps_start: float = 1.0, eps_end: float = 0.05, perimeter: float = 0.0)`

Two-phase field ``x ∈ {lo, hi}`` via a sharpening level-set head.

  - `curriculum_hints(self)`
  - `head(self) -> Head`
  - `interval(self)`
  - `losses(self, field_name, context=None)`

### `class Bounded(lo: float = 0.0, hi: float = 1.0, init: float | None = None)`

``lo ≤ x ≤ hi`` through a sigmoid head (NeFTY Eq. 6).

  - `head(self) -> Head`
  - `interval(self)`

### `class CombinedPrior(priors: list[Prior], field: str = 'x', ndim: int | None = None, domain: Any = None, top: Prior = <factory>, periodic_axes: tuple[int, ...] = ())`

The resolved set of priors for one field (see :func:`combine`).

  - `auto_init` (property)
  - `base_head(self) -> Head`
  - `build_field(self, builder: Callable[[int], Field], ndim: int) -> Field` — Build the (possibly symmetry-wrapped) field; ``builder(ndim)`` makes the inner field.
  - `context(self) -> PriorContext`
  - `curriculum_hints(self) -> dict[str, Any]`
  - `describe(self) -> str`
  - `field_hints(self) -> dict[str, Any]`
  - `head(self) -> Head` — The output head: the top prior's head wrapped by modifiers (support, conservation).
  - `losses(self) -> LossSpec` — ``{name: (Loss, relative_strength)}`` of every prior (names made unique).
  - `postprocess(self) -> list[Postprocess]`

### `class Conserved(total: float = 1.0, kind: str = 'sum', hard: Any = 'auto', weight: float = 1.0)`

The field's total is known (mass / charge / number of particles).

  - `losses(self, field_name, context=None)`
  - `wrap_head(self, head, context)`

### `class KnownSupport(mask: Any = None, fill: float | None = None, hard: bool = True, weight: float = 1.0)`

The unknown vanishes (equals ``fill``) outside a known support ``mask`` (1 = inside).

  - `losses(self, field_name, context=None)`
  - `wrap_head(self, head, context)`

### `class Monotone(axis: int = 0, direction: str = 'increasing', weight: float = 1.0)`

Monotone along an axis (soft penalty on violations).

  - `losses(self, field_name, context=None)`

### `class NonNegative(init: Any = 'auto', beta: float = 1.0, peak_ratio: float = 3.0)`

``x ≥ 0`` through a softplus head (``x = s · softplus(h)``).

  - `head(self) -> Head`
  - `headroom(self) -> float`
  - `interval(self)`

### `class Periodic(axes: Any = None)`

Periodic domain along ``axes`` (default: all): regularizers wrap around; with all axes periodic the neural field uses a purely periodic Fourier encoding (no raw coordinates).

  - `field_hints(self, ndim=None)`
  - `resolved_axes(self, ndim: int | None) -> tuple[int, ...]`

### `class PiecewiseConstant(tv: float = 0.01, eps: float = 1e-06, isotropic: bool = True)`

Piecewise-constant field: total-variation penalty (isotropic, NeFTY Eq. 22).

  - `losses(self, field_name, context=None)`

### `class Positive(init: Any = 'auto')`

``x > 0`` with a log-parameterization ``x = s · exp(h)`` (large dynamic ranges).

  - `head(self) -> Head`
  - `interval(self)`

### `class Prior()`

Base class. Subclasses are dataclasses with a class-level ``key`` (DSL name).

  - `auto_init(self) -> bool` — True when the head's scale should be fitted to the data by ``from_forward``.
  - `curriculum_hints(self) -> dict[str, Any]` — Suggestions for :func:`nefi.auto.auto_curriculum` (e.g. ``anneal_fraction``).
  - `describe(self) -> str`
  - `field_hints(self, ndim: int | None = None) -> dict[str, Any]` — Suggestions for the representation (e.g. ``max_octaves``, ``include_input``).
  - `head(self) -> Head | None` — The output head, or ``None`` if this prior does not define one.
  - `headroom(self) -> float` — Ratio between the head's natural scale and the fitted initial level (1 = same).
  - `inner_ndim(self, ndim: int) -> int` — Coordinate dimension of the field wrapped by :meth:`wrap_field`.
  - `interval(self) -> tuple[float, float]` — Values allowed by this prior (used to check compatibility with other priors).
  - `losses(self, field_name: str, context: PriorContext | None = None) -> LossSpec` — ``{name: (Loss, relative_strength)}`` contributed by this prior.
  - `params(self) -> dict[str, Any]`
  - `parse(spec: Any) -> list[Prior]` — Parse the prior DSL (or pass through Prior objects / lists) into a list of priors.
  - `postprocess(self, field_name: str | None = None) -> list[Postprocess]`
  - `rank(self) -> int` — Specificity of the head this prior defines (``-1``: no head).
  - `wrap_field(self, inner: Field, ndim: int) -> Field`
  - `wrap_head(self, head: Head, context: PriorContext) -> Head` — Wrap the resolved head (head modifiers such as known support / conservation).

### `class PriorContext(field: str = 'x', ndim: int | None = None, domain: Any = None, periodic_axes: tuple[int, ...] = (), value_range: tuple[float, float] = (-inf, inf))`

Information shared with priors while building losses / heads / fields.

### `class PriorList(iterable=())`

A list of priors supporting ``+`` with priors, strings and lists.

### `class Scale(homogeneity: float | None = None)`

Recover the absolute scale after fitting (energy-anchored correction, NeTMY Eq. 30).

  - `postprocess(self, field_name=None)`

### `class Smooth(laplacian: float | None = None, tikhonov: float | None = None, gradient: float | None = None)`

Smooth field: Laplacian (second-order), gradient (first-order Tikhonov) and/or ridge penalties. With no argument: ``laplacian=1e-2``.

  - `field_hints(self, ndim=None)`
  - `losses(self, field_name, context=None)`

### `class Sparse(l1: float = 0.01, gated: bool = True, init: Any = 'auto', peak_ratio: float = 30.0)`

Mostly-zero, non-negative field: gated softplus head (NeTMY Eq. 5) + L1 penalty.

  - `auto_init(self) -> bool`
  - `head(self) -> Head | None`
  - `headroom(self) -> float`
  - `interval(self)`
  - `losses(self, field_name, context=None)`
  - `rank(self) -> int`

### `class Symmetric(kind: str = 'mirror_x', axes: Any = None, hard: bool = True, weight: float = 1.0)`

Mirror or radial symmetry, exact by coordinate folding (``hard``) or as a penalty.

  - `inner_ndim(self, ndim: int) -> int`
  - `losses(self, field_name, context=None)`
  - `wrap_field(self, inner, ndim)`
  - `wraps_field` (property)

### `class Unconstrained(init: Any = 'auto', scale: float = 1.0, offset: float = 0.0)`

Signed, unconstrained values (identity/affine head).

  - `head(self) -> Head`

### `def combine(priors: Any, field: str = 'x', ndim: int | None = None, domain: Any = None) -> CombinedPrior`

Resolve a set of priors for one field: pick the head, check compatibility.

### `def describe_catalogue() -> str`

Markdown table of the DSL (name, class, meaning) — used by the docs.

### `def parse(spec: Any) -> list[Prior]`

Parse ``spec`` (DSL string, Prior, list/tuple of those, CombinedPrior) into priors.

### `def register_prior(name: str, cls: type[Prior]) -> type[Prior]`

Make a custom :class:`Prior` subclass available in the DSL under ``name``.

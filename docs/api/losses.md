## `nefi.losses.base`

Loss composition: a :class:`Context` per step, :class:`Loss` terms, and a weighted :class:`LossSet`.

### `class Context(fields: dict[str, torch.Tensor], pred: torch.Tensor, obs: Measurement, domain: Domain, operator: Operator | None = None, field_module: Field | None = None, ...`

Everything a loss term may look at during one optimization step.

  - `field(self, name: str | None = None) -> torch.Tensor`

### `class Loss(name: str | None = None)`

A scalar loss term. ``is_data`` marks data-fidelity terms (used for stopping / restarts).

  - `forward(self, ctx: Context) -> torch.Tensor`

### `class LossSet(losses: Mapping[str, Loss | dict | str] | Sequence[Loss], weights: Mapping[str, float] | None = None)`

Weighted sum of named loss terms with per-stage weight overrides.

  - `auto_balance(self, ctx: Context, target: float = 1.0, only: Sequence[str] | None = None)` — Rescale weights so each active term contributes ``target`` at the current iterate.
  - `data_loss(self, comps: Mapping[str, float]) -> float` — Weighted sum of the data-fidelity components of a ``comps`` dict.
  - `data_terms(self) -> tuple[str, ...]`
  - `forward(self, ctx: Context) -> tuple[torch.Tensor, dict[str, float]]`
  - `forward_tensors(self, ctx: Context) -> tuple[torch.Tensor, dict[str, torch.Tensor]]` — Total loss and *detached tensor* components (no device synchronization).
  - `names` (property)
  - `with_weights(self, overrides: Mapping[str, float] | None) -> LossSet` — Shallow copy sharing the loss modules with (partially) overridden weights.

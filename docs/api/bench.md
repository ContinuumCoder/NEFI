### `class FnModifier(fn: Callable[[Any, Curriculum], Any], name: str | None = None)`

### `class Modifier()`

Changes one component of a method. Override any of the hooks.

  - `apply(self, problem: Any, curriculum: Curriculum) -> tuple[Any, Curriculum]` — Apply the problem and curriculum hooks.
  - `config(self, cfg: Any) -> dict[str, Any]` — Instance-config overrides (applied before the problem is built).
  - `curriculum(self, curriculum: Curriculum) -> Curriculum` — Return the (possibly new) curriculum; in-place changes may return ``None``.
  - `problem(self, problem: Any) -> Any` — Return the (possibly new) problem; in-place changes may return ``None``.

Ablation table with one method per (cumulative) step (NeTMY Tab. 3, NeFTY Tab. 3).

### `def drop_loss(name: str) -> Modifier`

### `def grid_field(lr_scale: float = 1.0) -> Modifier`

### `def no_annealing() -> Modifier`

Disable frequency annealing: every stage starts with all Fourier bands on.

### `def no_gate() -> Modifier`

Replace every :class:`GatedSoftplus` head by a plain :class:`Softplus` (NeTMY "−gate").

### `def no_positional_encoding() -> Modifier`

Replace the Fourier-feature encoding of a :class:`NeuralField` by raw coordinates.

## `nefi.bench.protocol`

Benchmark protocol: paired, seeded, inverse-crime-safe comparisons with confidence intervals.

### `class BenchmarkResult(instance: str, rows: list[dict[str, Any]], methods: list[str], metric_names: list[str], config: dict[str, Any] = <factory>, regime: dict[str, str] = <factor...`

Per-run rows of a benchmark plus aggregation and report writers.

  - `best(self, metric: str) -> str | None` — Method with the best mean ``metric`` (``None`` if the direction is unknown).
  - `direction(self, metric: str) -> bool | None` — ``True`` if higher is better for ``metric`` (``None`` if unknown).
  - `efficiency_table(self, precision: int = 3) -> str` — Training-level efficiency (NeFTY Tab. 9): params, steps, ms/step, wall-clock, memory.
  - `header(self, ci: float = 0.95) -> str`
  - `load(path: str | Path) -> BenchmarkResult` — Load from a ``benchmark.json`` file or a directory written by :meth:`save`.
  - `merge(paths: str | Path | Sequence[str | Path], strict: bool = True) -> BenchmarkResult` — Concatenate benchmark shards into one result (the table of the unsharded run).
  - `ok_rows(self) -> list[dict[str, Any]]`
  - `save(self, directory: str | Path, ci: float = 0.95) -> dict[str, Path]` — Write ``summary.md``, ``summary.csv``, ``rows.csv`` and ``benchmark.json``.
  - `save_shard(self, directory: str | Path) -> Path` — Write this shard as ``<directory>/shard-III-of-NNN.json`` (merge with :meth:`merge`).
  - `shard` (property) — ``(i, n)`` if this result is shard ``i`` of ``n`` (see ``run_benchmark(shard=...)``).
  - `shard_filename(self) -> str`
  - `shard_files(directory: str | Path) -> list[Path]` — Shard files (``shard-*-of-*.json``) in ``directory``, sorted.
  - `strata(self, prefix: str = 'scene/') -> list[str]` — Row columns available for stratification (``scene/*`` by default).
  - `summary_csv(self, ci: float = 0.95, by_class: bool = False, by: str | None = None) -> str` — Aggregated table as CSV (``by`` groups by any row column, e.g. ``"scene/n_defects"``).
  - `table(self, ci: float = 0.95, by_class: bool = False, metrics: Sequence[str] | None = None, by: str | None = None) -> list[dict[str, Any]]` — Aggregated rows: mean and t-distribution CI half-width over samples × seeds.
  - `to_csv(self, path: str | Path | None = None) -> str` — Raw per-run rows as CSV (written to ``path`` when given).
  - `to_dict(self) -> dict[str, Any]`
  - `to_json(self, path: str | Path | None = None) -> str` — Everything (settings + raw rows) as JSON (written to ``path`` when given).
  - `to_markdown(self, ci: float = 0.95, by_class: bool = False, precision: int = 4, bold_best: bool = True, runtime: bool = True, header: bool = True, by: str | None = None...` — Markdown table ``method | metric ↑/↓ … | time | peak mem | steps`` with best in bold.

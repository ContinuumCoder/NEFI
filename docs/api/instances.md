Instance protocol: a self-contained, registered exemplar inverse problem.

  - `build_problem(self, measurement: Measurement) -> InverseProblem`

  - `config_dict(self) -> dict`
  - `data_generator(self) -> DataGenerator`
  - `default_curriculum(self) -> Curriculum`
  - `default_scene_class(self) -> str | None` — Scene class used when ``run``/``make_measurement`` get none (``cfg.scene`` if set).
  - `domain(self) -> Domain`
  - `evaluate(self, result: Result, gt: Mapping[str, torch.Tensor]) -> dict[str, float]`

  - `metrics(self) -> dict[str, Callable]`
  - `refine(self, result: Result, measurement: Measurement, **kw: Any)` — Edge refinement of a reconstruction of ``measurement``: a short second optimization under the same operator and data with a level-set (piecewise-constant) prior, phase values from the instance configuration (``nefi.solve.refine.REFINE_DEFAULTS`` or a ``refine_defaults`` attribute).
  - `run(self, seed: int = 0, device: str = 'auto', scene_class: str | None = None, curriculum: Curriculum | None = None, callbacks: Sequence = (), **solver_kw) -> R...`

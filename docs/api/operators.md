### `class ImplicitSystem(stencil: DiffusionStencil, dt: float)`

``A(α) = I - Δt L(α)``: symmetric, strictly diagonally dominant, SPD (NeFTY App. D.2).

  - `apply(self, T: torch.Tensor) -> torch.Tensor` — ``A T``.
  - `apply_offdiag(self, T: torch.Tensor) -> torch.Tensor` — ``R T`` with ``A = D + R`` (the Jacobi splitting of NeFTY Eq. 24).
  - `chebyshev_omegas(self, iters: int) -> list[torch.Tensor]` — :func:`chebyshev_omegas` for this system (cached per ``iters``; constants for autograd, i.e. the ``grad_mode="autograd"`` gradient treats the iteration's weights as fixed).
  - `chebyshev_sweeps(self, b: torch.Tensor, x: torch.Tensor, iters: int) -> torch.Tensor` — ``iters`` Chebyshev-accelerated Jacobi iterations (semi-iterative method).
  - `jacobi_sweep(self, b_scaled: torch.Tensor, x: torch.Tensor) -> torch.Tensor` — One fused Jacobi sweep ``D⁻¹(b - R x)`` given ``b_scaled = D⁻¹ b`` (Eq. 24).
  - `jacobi_sweep_weights(self) -> list[torch.Tensor]` — ``W_j = -R_j / D`` so that one Jacobi sweep is ``x ← b/D + Σ_j W_j ⊙ shift_j(x)``.
  - `jacobi_sweeps(self, b: torch.Tensor, x: torch.Tensor, iters: int) -> torch.Tensor` — ``iters`` fused Jacobi sweeps ``x ← D⁻¹b + Σ_j W_j ⊙ shift_j(x)`` (NeFTY Eq. 24).
  - `layout` (property)
  - `spectral_bound(self) -> torch.Tensor` — Gershgorin bound ``ρ = max_i Σ_j W_j[i] < 1`` for the spectral radius of the Jacobi map (0-dim tensor, no gradient; the eigenvalues of ``D⁻¹R`` are real since ``A`` is symmetric).

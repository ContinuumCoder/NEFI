## `nefi.baselines.gaussian_splat`

Explicit Gaussian-splat parameterization — the *GaussianSplat* baseline (NeTMY App. E.2).

### `class GaussianSplatField(ndim: int, heads: Heads | Mapping | None = None, n_primitives: int = 64, max_primitives: int = 128, init: str = 'grid', init_sigma: float | None = None, ini...`

Sum of anisotropic Gaussian primitives rendered onto the query grid (NeTMY App. E.2).

  - `add(self, means: torch.Tensor, sigmas: torch.Tensor, amps: torch.Tensor) -> torch.Tensor` — Place new primitives into free slots (as many as fit); returns their slot indices.
  - `amplitudes` (property) — Amplitudes ``(K_max, C)`` (inactive slots included; see :attr:`active`).
  - `deactivate(self, idx: torch.Tensor)`
  - `extra_repr(self) -> str`
  - `free_slots(self) -> torch.Tensor` — Indices of inactive slots, longest-inactive first (limits stale optimizer moments).
  - `means` (property) — Positions ``(K_max, d)`` in normalized coordinates.
  - `n_active` (property)
  - `raw(self, coords: torch.Tensor, progress: float = 1.0) -> torch.Tensor`
  - `reset_parameters(self)` — Re-initialize the first ``n_primitives`` slots (active) and clear the rest.
  - `set_primitives(self, means: torch.Tensor, sigmas: torch.Tensor, amps: torch.Tensor)` — Replace the whole primitive set (``len(means) <= max_primitives``).
  - `sigmas` (property) — Per-axis widths ``(K_max, d)`` in normalized units.
  - `write(self, idx: torch.Tensor, means: torch.Tensor, sigmas: torch.Tensor, amps: torch.Tensor)` — Set slots ``idx`` to the given primitives and mark them active.
